# Contributing

## Issues

Open an issue for bugs and change proposals. For bugs, include the platform, the OS version, the app version, and the steps that lead to the problem.

## Development

Setup and build commands are in the [README](README.md). The CI workflow runs analysis, tests and build checks for Android and iOS on every pull request. It must pass before a pull request is merged.

## Pull requests

- Keep each pull request to one change.
- Describe what changes and link the related issue.
- Add or update tests for changed behavior.
